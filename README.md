# 🐰 Coelho Moto Peças

Projeto web full stack desenvolvido para uma loja real de motopeças.

O sistema possui catálogo de produtos, peças, acessórios e pneus, além de um painel administrativo para gerenciamento da loja.

## 🚀 Projeto online

🔗 https://coelho-moto-pecas.onrender.com

## 🛠️ Tecnologias

- Python
- Django
- HTML
- CSS
- JavaScript
- PostgreSQL
- Neon
- Cloudinary
- Render
- GitHub

## ⚙️ Funcionalidades

- Catálogo de peças
- Catálogo de acessórios
- Catálogo de pneus
- Layout responsivo
- Integração com WhatsApp
- Painel administrativo
- Cadastro e edição de produtos
- Controle de preços
- Controle de estoque
- Variações de produtos
- Upload de imagens
- Banco de dados PostgreSQL
- Deploy em nuvem

## 🗄️ Infraestrutura

Código e aplicação:
- Django + Render

Banco de dados:
- PostgreSQL hospedado no Neon

Imagens:
- Cloudinary
